# カード明細家計簿

カード明細CSVをブラウザに貼り付けるだけで、支出合計とカテゴリ別集計を自動計算するWebアプリです。

## 機能

- CSVファイルのアップロード（Shift-JIS・UTF-8 自動判別）
- テキストエリアへの直接貼り付け
- 2種類のCSVフォーマットを自動判別
- カテゴリ自動分類（優先順位順）：
  保険・ゴルフ・宿泊費・AI関連・ネット買い物・交通費・サブスク・食費・日用品・買い物・その他
- 支出合計・カテゴリ別合計をリアルタイム表示
- Excelファイル（.xlsx）でのダウンロード
  - シート①：サマリー（合計・カテゴリ別）
  - シート②：明細一覧
  - シート③：読み取れなかった行
- LocalStorageによるデータ保存（ブラウザを閉じても保持）

## カテゴリ自動分類ルール

上から順に評価し、最初に一致したカテゴリに分類されます。
大文字・小文字・全角・半角の違いは無視します（例：amazon / AMAZON / ＡＭＡＺＯＮ はすべて同じ扱い）。

| 優先順位 | カテゴリ | 判定キーワード（例） |
|:---:|---|---|
| 1 | 保険 | 保険 |
| 2 | ゴルフ | ゴルフ |
| 3 | 宿泊費 | ラクテントラベル・アゴダ |
| 4 | AI関連 | AI・OpenAI・ChatGPT・Gemini 等 |
| 5 | ネット買い物 | Amazon・アマゾン |
| 6 | 交通費 | JR・JAL・ANA・エーエヌエー・地下鉄・バス・タクシー 等 |
| 7 | サブスク | Netflix・Spotify・YouTube・チョコザップ・アオバ・ノート 等 |
| 8 | 食費 | コンビニ・スーパー・レストラン・カフェ 等 |
| 9 | 日用品 | ドラッグストア・薬局 等 |
| 10 | 買い物 | 楽天・Yahoo・メルカリ 等 |
| 11 | その他 | 上記以外すべて |

> キーワードの追加・変更は `src/utils/categorizer.js` の `RULES` 配列を編集してください。

## 対応CSVフォーマット

| フォーマット | 特徴 |
|---|---|
| フォーマット1 | 先頭列が「ショッピング/キャッシング/その他」の形式 |
| フォーマット2 | 「利用日・利用先名称・利用金額」の列ヘッダがある形式（タカシマヤカード等） |

## セキュリティ

- すべての処理はブラウザ内のみで完結
- 外部サーバーへのデータ送信なし
- カード番号・氏名などの個人情報はコードに含まれていません

## 使い方

1. [アプリを開く](https://hiro0112.github.io/kakeibo/)
2. 「CSVファイルを選択」でファイルをアップロード、またはテキストエリアにCSVを貼り付け
3. 「解析する」ボタンをクリック
4. 結果を確認し「Excelファイルをダウンロード」で保存

## ローカルで動かす

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/kakeibo/` を開く

## GitHub Pagesへデプロイ

```bash
npm run deploy
```

GitHubリポジトリの Settings → Pages → Source を `gh-pages` ブランチに設定してください。
