# カード明細家計簿

カード明細CSVをブラウザに貼り付けるだけで、支出合計とカテゴリ別集計を自動計算するWebアプリです。

## 機能

- CSVファイルのアップロード（Shift-JIS・UTF-8 自動判別）
- テキストエリアへの直接貼り付け
- 2種類のCSVフォーマットを自動判別
- カテゴリ自動分類（食費・交通費・買い物・サブスク・日用品・その他）
- 支出合計・カテゴリ別合計をリアルタイム表示
- Excelファイル（.xlsx）でのダウンロード
  - シート①：サマリー（合計・カテゴリ別）
  - シート②：明細一覧
  - シート③：読み取れなかった行
- LocalStorageによるデータ保存（ブラウザを閉じても保持）

## 対応CSVフォーマット

| フォーマット | 特徴 |
|---|---|
| フォーマット1 | 先頭列が「ショッピング/キャッシング/その他」の形式 |
| フォーマット2 | 「利用日・利用先名称・利用金額」の列ヘッダがある形式（タカシマヤカード等） |

## セキュリティ

- すべての処理はブラウザ内のみで完結
- 外部サーバーへのデータ送信なし
- カード番号・氏名などの個人情報はコードに含まれていません

## 使い方

1. [アプリを開く](https://hiro0112.github.io/kakeibo/)
2. 「CSVファイルを選択」でファイルをアップロード、またはテキストエリアにCSVを貼り付け
3. 「解析する」ボタンをクリック
4. 結果を確認し「Excelファイルをダウンロード」で保存

## ローカルで動かす

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/kakeibo/` を開く

## GitHub Pagesへデプロイ

```bash
npm run deploy
```

GitHubリポジトリの Settings → Pages → Source を `gh-pages` ブランチに設定してください。
